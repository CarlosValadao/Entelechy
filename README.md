# 🚀 Entelechy Project

O **Entelechy** é uma placa de propósito geral baseado na arquitetura **8051**.
Este projeto faz parte do meu portfólio de desenvolvimento em **Engenharia de Computação na UEFS** e minha trajetória na residência tecnológica do **CEPEDI**.

## 🛠️ Especificações de Hardware

### **Núcleo de Processamento**
* **MCU:** Atmel AT89S51 (Arquitetura 8051).
* **Interface de Programação:** Conector **ISP Prog** dedicado para gravação em circuito.

### **Sensores e Atuadores**
* **Display:** LCD 16x2 com interface **I2C** para visualização de dados em tempo real.
* **Temperatura/Humidade:** Sensor **DHT22** para medições de temperatura e umidade relativa.
* **Indicadores Visuais:** * LED **RGB** (Azul) e LEDS comuns (Laranja).
* **Feedback Sonoro:** Buzzer passivo para alertas via PWM.
* **HMI:** 4 Push-buttons e 8 Slide Switches.

### **Gerenciamento de Energia**
* **Proteção:** Circuito integrado contra **inversão de polaridade**.
* **Regulação:** Reguladores de tensão onboard com dissipadores para estabilidade térmica.
